# Methodology

## Purpose

The IFRS Forensic Assurance Algorithm is a research framework for analysing
selected sustainability disclosures through evidence traceability,
recalculation, data quality and control-oriented tests.

## Important distinction

The framework's DQS, Forensic Assurance Index, HHI application, Gender Share
Gap and Alpha-Zinc states are research constructs. They are not requirements
defined by IFRS S1 or IFRS S2.

## Core flow

Source evidence -> normalisation -> lineage -> calculation -> verification ->
data quality -> exceptions -> assurance index.

## Reproducibility

All reference calculations are deterministic except verification IDs and
timestamps, which are generated for audit-log uniqueness.
